# Skill Advance

Proyecto de demostracion para una skill propia de diagnostico de Apify.

`feat/apify-health-check-skill`

## Contenido

- `.codex/skills/apify-health-check/`: skill con scripts, assets y referencias.

Consulta `.codex/skills/apify-health-check/SKILL.md` para conocer los
requisitos, el flujo completo y los ejemplos de entrada y salida.
